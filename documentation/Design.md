📱 Gym Tracking Mobile App – UI/UX Design Brief
Project Overview
I’m building a modern gym tracking mobile app focused on workout logging, split creation, and performance tracking. The goal is to create a minimalist, sleek, premium-feeling experience that feels effortless to use in the gym.

Design Style & Aesthetic

Overall vibe: Minimal, clean, modern, and slightly aggressive (strength-focused but refined)

Primary color: Black (dominant background color)

Accent colors: Very minimal usage (e.g., white, light gray, subtle muted accent if needed)

Avoid: Overly colorful UIs, cluttered screens, unnecessary gradients, or “gimmicky” fitness visuals

Visual Inspiration (Conceptual)

High-end fitness brands

Apple Fitness (simplicity, spacing)

Whoop / Nike Training Club (but darker and more minimal)

Emphasis on typography, spacing, and hierarchy over visuals

Typography

Clean, modern sans-serif font

Strong contrast between headers and body text

Readable in low-light gym environments

UI Principles

Black or near-black backgrounds for most screens

Clear visual hierarchy with ample spacing

Subtle dividers and elevation instead of heavy borders

Smooth, intentional interactions (no cluttered controls)

Optimized for one-handed use during workouts

Key Screens to Focus On

Onboarding flow

Home / Dashboard

Today’s Workout (log sets, reps, weights)

Exercise selection/search

Split creation & workout templates

Profile / settings

UX Goals

Fast to log workouts

Low cognitive load during training

Minimal taps to complete actions

UI should “get out of the way” while lifting

Deliverables

High-fidelity mobile designs (iOS-first, but platform-agnostic)

Design system / components (buttons, inputs, cards, typography)

Dark-mode–first layouts

Figma file with organized components and styles

Success Criteria
A user should feel that the app is:

Premium

Focused

Distraction-free

Built for serious training
